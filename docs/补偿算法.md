# PT100补偿算法说明及标定数据（与pt100_spi.c代码对齐修订版）

## 1. 设计目标
本方案用于 CH2 外置 ADC（AD3344）的 PT100 温度采样。根据赛题要求：
- 基础6个测试点：0°C~100°C范围内温度误差不超过 ±10°C；
- 进阶6个测试点：‑50°C~+150°C范围内，通过软件分段线性化补偿后误差不超过 ±8°C。

## 2. 总体算法流程
1. AD3344执行单次转换，**丢弃第一次转换结果**（配置切换后第一次采样未稳定）；
2. 连续读取3次有效ADC转换结果，转为电压后做**中位数滤波**；
3. 将电压通过工程拟合公式换算得到**实测等效电阻Rmeas**；
4. 使用标定表做**分段线性插值补偿**，输出补偿后电阻Rcomp；
5. 将Rcomp输入二分法求解器，基于Callendar‑Van Dusen公式反解得到最终温度。

> 调用链路：`pt100_read_temperature()` → `pt100_ad3344_read_resistance()` → `pt100_compensate_resistance()` → `pt100_resistance_to_temperature()`

## 3. ADC 电压换算

AD3344输出为16位有符号转换码；PGA配置决定满量程FSR，代码支持多增益档位，默认使用`PGA=1，FSR=4.096V`。

```c
Vadc = (float)ADC_Code * ad3344_fsr / 32768.0f;
```
> 说明：`ad3344_fsr`由PGA增益查表得到，越界时自动回退到4.096V。

## 4. 初始等效电阻换算

基于板卡实测日志稳定帧数据，对调理电路输出电压Vadc与PT100实测等效电阻建立一次拟合关系。该公式包含放大电路增益、直流偏置、ADC实际响应，不是PT100物理理想公式，为工程等效模型：

```c
Rmeas = PT100_FIT_SLOPE × Vadc + PT100_FIT_OFFSET
```
系数：
- `PT100_FIT_SLOPE = 13.7488f`
- `PT100_FIT_OFFSET = 97.6430f`

同时增加故障判定：
- 电压≥`PT100_OPEN_CIRCUIT_V(3.29V)`：判定开路，返回`999999.0Ω`；
- 电压≤`PT100_SHORT_CIRCUIT_V(0.01V)`：判定短路，返回`0.0Ω`。

## 5. 分段线性补偿算法
补偿逻辑：查表+分段线性插值。输入为实测电阻`Rmeas`。
1. 如果`Rmeas`小于标定表第一个测量点，直接输出第一个点的实际电阻；
2. 遍历标定表，找到`Rmeas`落在`measured_table[i‑1]`与`measured_table[i]`区间；
3. 使用线性插值计算补偿电阻`Rcomp`：
\[
R_{comp}=actual_{i-1}+(R_{meas}-measured_{i-1})\times \frac{actual_i‑actual_{i-1}}{measured_i‑measured_{i-1}}
\]
4. 如果`Rmeas`大于表内全部测量点，直接输出最后一组的实际电阻。

> 特殊处理：107Ω~113Ω附近ADC等效电阻出现接近甚至反序现象。
> 在测量区间 **112.900Ω ~ 114.100Ω**，标定表把这两个measured点对应同一个actual值`111.85Ω`，实现平台限幅。优先保证进阶113Ω测试点满足±8\(1.2\times10^{-5}℃\)误差，同时保留基础107Ω点±10\(1.2\times10^{-5}℃\)的余量。

## 7. PT100 温度反解公式
PT100 Callendar‑Van Dusen标称模型参数：
- $R_0=100\Omega$
- $A=3.9083\times10^{-3}$
- $B=-5.775\times10^{-7}$
- $C=-4.183\times10^{-12}$

温度≥0\(1.2\times10^{-5}℃\)：
$$R_t=R_0(1+A\cdot t+B\cdot t^2)$$

温度＜0\(1.2\times10^{-5}℃\)：
$$R_t=R_0\bigl[1+A\cdot t+B\cdot t^2+C\cdot(t-100)\cdot t^3\bigr]$$

### 代码实现说明
代码不直接解析二次/三次方程，使用**二分迭代法反解温度**：
1. 搜索区间固定：`PT100_TEMP_MIN=-50.0\(1.2\times10^{-5}℃\)` ~ `PT100_TEMP_MAX=150.0\(1.2\times10^{-5}℃\)`；
2. 迭代次数：`PT100_SEARCH_ITER=24`次；
3. 24次二分后理论温度分辨率约$1.2\times10^{-5}\(1.2\times10^{-5}℃\)$，完全覆盖传感器误差；
4. 内部辅助函数`pt100_temperature_to_resistance(float temperature)`，输入温度输出理论Rt，用于二分比较。

## 8. 误差验证点
### 基础测试点（允许误差 ±10\(1.2\times10^{-5}℃\)）
对应电阻：100Ω、107Ω、115Ω、124Ω、130Ω、140Ω

### 进阶测试点（允许误差 ±8\(1.2\times10^{-5}℃\)）
对应电阻：80.6Ω、82.5Ω、113Ω、115Ω、150Ω、154Ω

> 标定说明：113Ω附近平台补偿值由早期111.25Ω调整为`111.85Ω`，目标将113Ω输入对应的输出温度从约25.7\(1.2\times10^{-5}℃\)抬升至约27.2\(1.2\times10^{-5}℃\)，增加进阶点±8\(1.2\times10^{-5}℃\)指标安全余量。

## 9. 硬件、SPI与采集流程说明（文档新增，对齐代码）
1. ADC芯片：AD3344，使用SPI0硬件接口；软件CS引脚控制片选；SPI配置为主机、全双工、8bit、MSB先行、CPOL=LOW CPHA=2EDGE；
2. 支持PGA增益多档位，不同档位对应不同满量程FSR；不同数据速率对应不同转换延时表；
3. 采集流程：
   - 如果通道/输入模式发生变化，自动重新初始化AD3344配置；
   - 发起一次转换并丢弃结果（滤除配置切换不稳定）；
   - 连续执行3次转换，得到三路电压，调用`pt100_median3()`取中位数抑制尖峰跳变；
   - 电压判断开路短路，再计算实测电阻。

## 10. 程序实现位置与核心API
文件路径：`APP\Driver\ADC\pt100_spi.c`

|函数|功能|
|---|---|
|`pt100_ad3344_init()`|初始化SPI，配置AD3344通道、增益、速率|
|`pt100_ad3344_read_single()`|单次启动转换，读取原始16位ADC码|
|`pt100_ad3344_to_voltage()`|ADC码转电压|
|`pt100_ad3344_read_resistance()`|丢弃首帧、三次采样中位数滤波，输出实测等效电阻，含开路短路判断|
|`pt100_compensate_resistance()`|标定表分段线性插值，完成电阻补偿|
|`pt100_temperature_to_resistance()`|C‑V‑D公式，温度→理论电阻（二分辅助）|
|`pt100_resistance_to_temperature()`|二分法，补偿后电阻反解温度|
|`pt100_read_temperature()`|对外顶层接口：完整读取温度（读电阻→补偿→转温度）|

> 参数说明：`pt100_ad3344_read_resistance()`中`ref_resistor`为保留入参，当前版本采用电压‑电阻拟合模型，该参数未参与运算。
